## Windows 10/11：

1.先确定你的设备有没有拿到公网 ipv6，北科校园网只有 V6 和 Student 能用公网 v6，不同地区表现不同，有的时候系统显示有公网 v6 地址但实际出口被拦，所以最好**网站检测**。

浏览器访问 [ippure.com](https://ippure.com/) 或 [testipv6.cn](https://www.testipv6.cn/)，如果有 v6 地址可以进行下一步。如果网站显示没有但系统设置里显示有公网 ipv6（非 fe80:: 开头），可以使用以下方法重置网络堆栈：右键任务栏 win 图标，选择终端管理员，逐条执行以下命令：

```bash
netsh int ipv6 reset

ipconfig /release6

ipconfig /renew6
```

然后断开 wifi 重新连接。

2.Win+R 输入 **ncpa.cpl** 回车打开控制面板网络连接，右键 WiFi，打开 **属性**

![1.webp](https://img.ich.cc.cd/file/ichblog/post_img/北科原生v6免流/1.webp)

3.找到 **ipv6 协议**，双击编辑

![2.webp](https://img.ich.cc.cd/file/ichblog/post_img/北科原生v6免流/2.webp)

4.选择“自动获取 ipv6 地址”、“使用下面的 DNS 服务器地址”，分别填上 `2a01:4f8:c2c:123f::1`、`2a01:4f9:c010:3f02::1`。注意使用英文冒号，不要有多余的空格

>注：如果出现问题尝试**只保留一个首选 DNS**，或更换其他 DNS（见文末）

![3.webp](https://img.ich.cc.cd/file/ichblog/post_img/北科原生v6免流/3.webp)

5.点击确定，**勾掉 ipv4 协议**，再点确定

![4.webp](https://img.ich.cc.cd/file/ichblog/post_img/北科原生v6免流/4.webp)

然后再去 [ippure.com](https://ippure.com/) 或 [testipv6.cn](https://www.testipv6.cn/) 检测一下，看到 ipv6 地址和 v6 优先就可以了。现在你使用的所有流量在校园网那都是 ipv6。

**怎么确定我使用了 ipv6？** 校园网流量统计有延迟，最好使用软件实时监控整个系统流量。推荐开源软件 [Sniffnet](https://sniffnet.net/)，可以[直接点击这里](https://github.com/GyulyVGC/sniffnet/releases/latest/download/Sniffnet_Windows_x64.msi)下载官方最新 Windows x64 安装程序，安装的时候会一并安装 Ncap，必须勾上 `Install Npcap in WinPcap API-compatible Mode`。如果出现问题使用管理员打开。选择你的网卡开始（[哪个是我的网卡？](https://doubao.com)），在主机一栏就可实时查看连接地址和流量统计。

## 恢复设置及其他问题

如果要登录校园网计费系统 202.204.48.66 需要在刚才的设置里**勾上 ipv4 协议**。切换其他 v4 网络也需要重新勾选，另外如果 ipv6 出现问题可以重新勾选 v6 “自动获得 DNS 服务器地址”。

可用性如何？日常使用不会有什么问题。速度慢？[教育网Cloudflare V6免流](https://ich.cc.cd/2026/03/30/%E6%95%99%E8%82%B2%E7%BD%91cloudflare%20v6%E5%85%8D%E6%B5%81/)

**能不能打游戏？** 不能，该用加速器就用，而且打游戏耗流量又不多。

**steam 下载**需要另外配置，具体可以看[这篇文章](https://imgs.ich.cc.cd/file/default/1775145791049_让_Steam_下载使用_IPv6_从而免流量.pdf)，或者[教育网Cloudflare V6免流](https://ich.cc.cd/2026/03/30/%E6%95%99%E8%82%B2%E7%BD%91cloudflare%20v6%E5%85%8D%E6%B5%81/)

为什么网站检测仍然显示我有 v4 地址？使用 DNS64，看到有 v4 地址是对的，但你的流量经过教育网计费系统的时候仍然是 v6 协议，所以无需担心收费问题。
